# Used Car Market Analysis | Power BI

## About the Project

This project is an interactive Power BI dashboard built to explore and understand the used car market.

I worked with used car data to analyze different aspects of the market, including car prices, brands, fuel types, transmission types, manufacturing years and locations.

The main aim was to turn raw data into meaningful insights through data cleaning, analysis and visualization.

## Key Performance Indicators

The dashboard includes the following KPIs:

- **Total Cars:** Total number of car records analyzed.
- **Average Selling Price:** Average price of the cars.
- **Maximum Selling Price:** Highest recorded car price.
- **Minimum Selling Price:** Lowest recorded car price.
- **Average Kilometres Driven:** Average distance covered by the cars.

## Analysis and Visualizations

The dashboard contains six main visualizations:

1. **Average Price by Brand** – Compares the average selling prices across car brands.
2. **Fuel Type Distribution** – Shows the distribution of cars across different fuel types.
3. **Cars by Transmission** – Compares manual and automatic transmission cars.
4. **Cars by Manufacturing Year** – Shows how the number of cars varies across manufacturing years.
5. **Price vs Kilometres Driven** – Explores the relationship between car prices and kilometres driven.
6. **Average Price by Location** – Compares average car prices across different locations.
